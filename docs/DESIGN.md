# AIGuide 设计约定

更新：2026-09-15。首页实现依据 `ui-redesign/aiguide-pages-v3-home.png`，配合全站 15 类桌面稿、8 张手机方案板与两张平板代表稿。工具目录和公司详情以新 [玻璃卡片设计](ui-tools-glass/design-notes.md) 为准；其他页面保持原设计。完整索引见 `ui-redesign/design-index.md`。较早的 `aiguide-home-v4.png` 属于之前的探索轮次，已不是当前首页依据。

## 视觉与结构

- 品牌：AIGuide。蓝色书页由两片不等高页形组成，中间保留清晰留白；导航与 favicon 使用同一形状。
- 首页主标题“从这里，学会 AI。”，页尾“先学会使用，再慢慢深入。”。
- 首页突出两类人群：蓝色“第一次使用 AI”、紫色“已有基础”，用 16px 加粗实色标签明确区分。入口卡使用半透明磨砂底、柔和色晕和细边缘高光；不支持背景模糊时回退到可读的浅色底。工具与操作入口同排，减少卡片高度与留白；手机窄屏按实际空间换行。下方保留六课入门路线与三张基础课程卡。
- 顶部仅保留学习路线、工具教程、模型指南三个主导航；搜索和继续学习在右侧。全部教程、实战项目、我的学习位于页尾与手机菜单。
- 桌面最大内容宽度 1280px，顶栏 80px；小屏逐步收为单列，不使用整体 CSS 缩放。
- 字体为系统中文无衬线；深蓝标题 `#14213D`、蓝色主操作 `#2F63F3`、次要文字 `#63718D`、浅蓝 `#EEF5FF`、浅紫 `#F1EEFF`、薄荷 `#E9F8F3`。
- 正文保持独立行宽，桌面右侧目录、手机折叠目录；具体内容、标题和按钮均为可选择的 HTML。
- 新手入口进入 `#/start`，选择豆包网页版或 WorkBuddy 桌面版。两种方式标明是否安装、任务步骤与成果，不合并成一套操作。基础六课路线保留豆包，WorkBuddy 有独立教程与成果记录；豆包工作模式仍在选学区。
- 编程主线称为“用 ChatGPT，做一个网页”，先做网络准备，再安装 ChatGPT 桌面版并进入 Codex。Codex 名称仅在对应编程入口、CLI 和云端等真实用法中保留。旧课程 ID 与正文 section 编号保持兼容。
- 网络准备从首页并列主卡移出，放在编程路线首课；学习路线和工具目录提供单独功能栏。已能使用目标工具时允许直接进入网页实操，不强制要求新手配置代理。
- 三个项目均提供材料与成果保存入口；“我的学习”新增成果列表，继续编辑直接定位到课程保存区。API练习台在浏览器中演示结构校验，不发送网络请求，明确保留事实核对边界。
- 模型详情的学习示例取自各自的专属教程；模型页的应用入口使用简短操作文案，确保320像素宽度也能完整显示。页尾提供“关于与来源”说明。
- 工具目录每家公司一张玻璃卡片，只分网页版、桌面版、API、模型。缺失的分类省略，终端教程移到公司详情的折叠进阶区；编辑器归入桌面版，仍保留其真实教程平台。公司与产品使用各自素材，原色不经滤镜修改。Kimi 白色字形保留深色承托。
- 图示说明标注示意；第三方应用是否已经合并入口，不改变教程按任务和使用端区分的原则。

## 交互与状态

2026-09-15新手流程补全：路线和核心实操课前置四项准备信息；可选自查不强制阻止阅读。中文流程图明确在哪个产品或页面操作，并标注为示意。问题帮助按当前卡点选择，可返回原章节，兼顾键盘焦点；原章节编号不变。豆包事实练习不替代账号实操。问题记录仅在本地生成，界面不显示虚假的提交成功。

独立阅读页从同一教程数据生成，保持蓝色书页标识、中文排版与来源说明；本页负责阅读，交互练习链接指向对应章节。正文、标题与摘要直接包含在HTML中，关闭JavaScript仍可阅读。发布域名未配置时不生成虚构canonical。

URL 保存查询与筛选；弹层区分草稿和已应用条件。返回列表恢复位置，继续阅读恢复章节。原生 dialog 管理弹层的焦点与 Escape，关闭后恢复触发控件焦点。手机优先保证 44px 主操作目标，尊重减少动态效果偏好。

学习完成需要逐项自查，可撤销。项目完成代表用户自行核对，不能显示成文件自动验证。学习记录仅本地保存，导入先预览再合并；损坏的原始记录先保护、再提供恢复出口。

模型排名已接入 Artificial Analysis 综合和终端编程评测，显示实际获取日期和源站未披露的评测日期。采用从零开始的紧凑竖向柱状图，横轴是模型、纵轴是分数，名称竖排。默认全部，支持前10名和前20名；桌面每列34px、手机每列44px，模型较多或窄屏时在图表内左右浏览，纵轴固定。柱顶直接显示分数，原色图标正向显示，完整配置在弹层中查看，来源方法在图下折叠；保留原始精度、学习入口、加载与失败恢复。名次只在本页收录范围内计算。其他来源和用途无数据时显示明确空状态。教程与产品页共享 SourceReview，区分官方资料依据、部分待核对与本站通用练习。

## 主要实现

- `Shell.jsx`、`GuideArt.jsx`、`Modal.jsx`：全站导航、书页标识、教学图和共享弹层。
- `LessonList.jsx`、`Shared.jsx`：课程列表、搜索、收藏、品牌与空状态。
- `styles.css`：基础样式、导航和共享组件；`styles-pages.css`：各页；`styles-reader.css`：正文与关系图。
- `ToolDirectory.jsx`、`CompanyLearningCard.jsx`、`company-learning.js`、`styles-tools.css`：公司目录与四类入口，桌面三列、平板两列、手机单列。
- `Start.jsx`、`NetworkPreparationLink.jsx`、`styles-start.css`：新手工具选择、共享准备入口与首页人群区分。
- 详情、目录、搜索、模型与学习记录各自分页面，内容数据独立维护。

历史 V4 的独立首页卡片组件和五份主题 CSS 已停止使用并移除；设计源图保留。旧轮次验收见 `../design-qa.md`；2026-09-15整合版本的验收范围见README。本轮资料核对与排名范围见 SOURCE-AUDIT.md；账号内实操、未接入的榜单与其他真实设备仍未覆盖。
