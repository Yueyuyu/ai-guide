# 后续迭代计划

工程基线已保存到 GitHub。以下记录待办、验收标准和已完成的仓库事项；未完成项可以逐项转成 GitHub Issue。

## P0：真实学习闭环

### LEARN-03 WorkBuddy 账号内实操

- 已补独立桌面教程、官方安装／工作空间／产物来源与练习材料，入口在新手工具选择和腾讯公司专题。
- 范围：安装登录、选择练习目录、生成实际周报、核对重复项与数字、修正并打开文件。
- 验收：在 WorkBuddy 内完成上述流程并保存脱敏证据。当前只完成官方文档核对与本站阅读流程验收，不计为账号内生成已通过。

### LEARN-01 豆包账号内实操

- 范围：登录、首次提问、按原文核对、同一对话追问、复制、回站保存。
- 验收：记录环境和日期，至少取得一次真实回答，保存脱敏证据，修正文中与实际界面不符的步骤。
- 边界：不将未登录截图或人工答案当作这项验收通过。

### LEARN-02 Codex 桌面完整流程

- 范围：官方安装与登录、选择练习目录、创建两个实际文件、局部修改、浏览器验收。
- 验收：在独立目录完成创建→修改→验收，确认文件路径、内容、导航、宽度与备份记录；标注未测系统。
- 边界：任务口头回复成功不代替实际文件，桌面入口不混为云端执行。

### UX-01 新手真人试用

- 范围：邀请第一次使用网站的人，独立完成选路线→准备→练习→保存。
- 验收：至少记录两次独立试用的停顿点、无法理解的术语和失败步骤，按严重程度修正后复查。
- 边界：浏览器自动化和开发者自查不计作真人试用。

### WEB-02 国内稳定直连

- 已完成：统计异步加载、主程序失败的中文阅读入口、正文故障恢复，以及国内电信／联通／移动节点的首次对比。
- 待定条件：域名备案、现有国内／香港托管服务及预算。确认后选择线路，先用临时测试入口验证再切换正式域名，不直接购买或迁移其他站点。
- 验收：同一批三网节点和真实手机／家庭宽带，在明确时段不使用 VPN 验证首页、教程、排名、材料下载；报告失败节点与完成时间。单次 HTTP 探测不等于真实阅读体验。
- 边界：免费 CDN 并不保证国内稳定；本站优化不改变第三方产品官网或 GitHub 反馈提交的访问条件。
