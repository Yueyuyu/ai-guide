# 公开试用、访问统计与赞助依据

公开试用提供豆包清单、WorkBuddy 文件任务、ChatGPT 网页练习，以及独立的网络准备反馈。先让读者完成任务，再依据真实卡点修改。教程有官方依据不等于账号内实测通过；已有 `codex` 反馈参数保持兼容。

## 反馈入口与接收

- 互动站：`/#/feedback`；每篇教程末尾有对应的纠错记录。
- 仓库：[实际试用反馈](https://github.com/Yueyuyu/ai-guide/issues/new?template=usage_feedback.yml)。
- 正文先在本地预览，移除常见 URL、订阅协议链接、密钥和邮箱。读者仍需人工检查；自动规则不能保证发现全部私人内容。
- 读者确认后跳转 GitHub，登录并主动提交。成功以 GitHub 的 Issue 编号为凭证；本站不把点击、复制或下载当作已接收。
- 过长记录保留完整内容，通过复制后粘贴到 GitHub，避免 URL 截断。
- 本站没有无需登录的反馈服务器。没有 GitHub 账号的读者可以先保存记录。

2026-09-15 接收演练：[维护测试 #1](https://github.com/Yueyuyu/ai-guide/issues/1) 已通过 GitHub CLI 创建、读回并关闭。网站表单的预览、脱敏、确认和登录跳转另经浏览器验证；尚未验证普通读者从登录到提交的全过程。该 Issue 明确标识非真人反馈，不计入试用人数、成功率或赞助受众。

## 真人试用怎么记录

每次记录：试用日期、教程主线、设备和软件版本、开始前的基础、实际停顿步骤、是否得到并打开成果、是否借助他人帮助、大约用时。无需收集姓名、联系方式、账户或个人订阅。

第一批争取至少两位新手独立尝试。主持者先观察，确实无法继续再帮助；被帮助完成的案例单独记录。开发者、自动化和示范操作均标为维护测试，不计入真人样本。

处理顺序：阻止继续的问题 → 步骤或入口失真 → 术语难懂 → 视觉建议。修正后回到相同步骤复查，并把修正链接和验证范围写回原 Issue。尚未出现真人反馈时保持“暂无”，不填示例人数。

## Cloudflare Web Analytics 接入

官方依据：[安装](https://developers.cloudflare.com/web-analytics/get-started/)、[SPA 统计](https://developers.cloudflare.com/web-analytics/get-started/web-analytics-spa/)、[数据收集](https://developers.cloudflare.com/web-analytics/data-metrics/data-origin-and-collection/)。2026-09-15 已读取安装与 SPA 文档。

1. 在 Cloudflare 控制台选择 Web Analytics，为正式域名 `ai-guide.yomexa.com` 配置站点。统计接入本身不要求迁移托管；域名指向按[发布指南](RELEASE.md)配置。
2. 选择手动添加脚本，取得代码中的 **站点公开 token**。它不是账户 API Token，也不是 Global API Key。
3. 在 GitHub 仓库 Settings → Secrets and variables → Actions → Variables 添加 `AIGUIDE_CF_ANALYTICS_TOKEN`。本机验证可使用忽略的 `.env.local`。
4. 触发“发布公开网站”。发布工作流将 token 传给构建，插件只在生产构建插入官方 beacon；开发服务不插入。未配置时不发出分析请求。
5. 打开正式网页，检查官方脚本和统计请求，再在控制台确认有数据。仅构建成功或看到脚本不能声称数据已接收。

初版显式设置 `spa: false`：只统计整页加载和性能，**不统计 Hash 路由切换、课程完成率或账号人数**。独立阅读页有不同 URL，可辅助比较内容阅读；互动站的课程切换不能当成完整漏斗。数据受脚本屏蔽、地区访问和采样影响；报告写清这些限制。关闭 JavaScript 仍可读独立正文，但不会产生客户端分析数据。

撤销接入：清空仓库变量并重新发布，同时在控制台停用站点。站内隐私文案按构建是否配置 token 显示，配置状态不代表后端已接收到数据。

2026-09-15 21:49（北京时间）已核对初始 GitHub Pages 站点：官方 beacon 脚本返回 200，RUM 统计端点返回 200／204；Cloudflare 控制台在“过去 24 小时、排除自动程序”条件下显示访问量 1、页面浏览量 1，并提示数据不足。22:07 已切换统计主机名至 `ai-guide.yomexa.com`，保留同一站点与公开标识；新域名页面的统计请求也返回 200／204。

上述记录处于维护验收期间，不作为真实受众证据。后续对外报告应选择验收结束后的完整统计周期，并另行排除维护访问；“排除自动程序”不保证能过滤全部开发者和自动化访问。

## 什么时候洽谈赞助

先准备一份注明统计起止日期的材料，包含实际整页访问、来源分布、有效真人反馈数、主要学习需求及已修复案例。注明数据源、样本量和维护测试排除方式，保留原始导出供复核。统计没有启用或数据不足时，不对外声称已有受众规模或转化率。

服务商候选核对兼容配置、费用、试用或退款、客服和实际可用性。客户端项目 README 的推广不是本站测试结论。商业条目明确标识“赞助”或“推广”，合作链接与官方教程来源分开；个人订阅 URL 永远不公开。当前没有联系赞助商或加入返佣链接。
