# 模型排名竖向柱状图

本次调整用于比较名次与分数：横轴为模型，纵轴为分数，柱子竖向增长。复用当前 React 与 CSS，单页只有一张图，默认展示全部，可切换前 10 名或前 20 名。最多约 120 个配置，无需新增图表依赖。React 管理布局、线性刻度、选择和详情；不用 Canvas 或仅悬停可见的提示。柱顶直接显示分数，下方显示名次、品牌原图与竖排的模型配置名称，文字也是图形不可读时的备用信息。

所有柱子从零开始。综合指标取完整榜单最大值向上取整到十的倍数，编程通过率固定 0–100%；同一指标切换显示数量不改变比例尺。纵轴刻度、单位直接显示，原始分数不变。统一蓝色表示分数高度，公司原始图标不改色，悬停或键盘焦点独立突出。细小差距不解释成显著能力差异。

来源、用途和显示数量写入 URL，缺失或非法数量回到全部，合法的前 10／20 名链接仍按其范围展示，返回与刷新可恢复。模型详情为临时选择，复用可关闭、能恢复焦点的 dialog，防止展开一行后撑长整张图。来源方法折叠在图下方，获取时间和源日期始终可见；失败保留已有快照。

桌面全部榜单每列 34px，1366px 与 1440px 视口下首屏可完整看到 36 个配置；手机每列 44px，保留触控空间。模型名与配置用两列竖排，英文整体旋转，不逐字母拆开；品牌图标保持正向和原色。分数横排保留两位小数，百分比单位统一标在纵轴，避免密集柱顶重复单位造成重叠。各配置仍独立按原始得分排序，不合并分数或调整名次。

超出可用宽度时在图表内部横向滚动，纵轴保持在左侧，整页不横向溢出。图下提供左右浏览按钮，图表聚焦后支持左右方向键、Home 和 End，Tab 可以依次进入模型按钮。手机同样保持模型在横轴、分数在纵轴。改变显示范围回到图表起点。无入场动画或缩放手势。验收覆盖比例尺、可见配置数量、分数和名称重叠、显示范围、横向滚动与末尾可达、详情键盘操作，以及桌面、平板和手机布局与构建。
