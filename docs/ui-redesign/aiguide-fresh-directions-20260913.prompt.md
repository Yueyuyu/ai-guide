# AIGuide 全新首页方向 · 2026-09-13

用户要求放下前一轮个人构想，重新探索几个差异明显的 UI 版本。本轮仅生成静态视觉设计稿，不修改网站实现。

目标：普通人访问 AIGuide 后，能从一个具体目标找到 AI 学习的第一步。保留产品身份、简体中文和正常控件尺寸；重新探索构图、视觉系统、品牌标识和文案。用户明确要求新的独立思路，因此生成不附带前一版参考图。

生成方式：内置 image_gen。三次独立生成，不使用 CLI。
目标尺寸：1440 × 1024 桌面首页。实际输出尺寸以文件为准。

方向名称只用于内部记录。用户选项编号必须按本轮设计图在聊天中的实际显示顺序确定，不按提示词提交顺序确定。

## 日常的学问

Use case: ui-mockup.
Create a realistic, production-quality finished desktop homepage UI for AIGuide, a Simplified Chinese website teaching ordinary people to use AI tools through practical lessons. The user wants a fresh creative redesign and several genuinely independent directions. Design one focused primary screen with clear hierarchy, strong typography, intentional imagery and purposeful spacing. Do not create a feature inventory. One clear primary action; only one or two supporting content areas.
Target dimensions: 1440 x 1024 desktop viewport, normal browser scale. Render website content only, no browser or device frame, no mockup surroundings, no multiple options on the same image. No warped, stretched or oversize UI. Body 14–16px, controls 42–48px tall, 32–80px spacing where purposeful. No more than two font families. Strong alignment, comfortable line lengths. All visible interface text must be accurate Simplified Chinese except the exact brand AIGuide and established product names. No fake customer metrics, no testimonials, no dates, no subscriptions or prices. Current date anchor if any date is unavoidable: 2026-09-13. This is a static concept, avoid claims of live statistics.
The brief intentionally resets the visual direction: do NOT use previous images, mountains, landscape, pastel split-screen gradients, seedling icons, paper planes, little robots, AI sparkle logos, or the previous twin novice/expert entry arrangement. These are deliberately new designs from scratch. Preserve only the product identity and Chinese beginner-friendly learning purpose. Do not force users to identify as beginner/expert or understand models before starting. Company directories and advanced tool learning may exist deeper off-screen.
Use typography, space and alignment first, then lightweight row dividers; surface tints only when useful. No cards inside cards, no repetitive bento grid, no excessive pills or floating tiny badges, no meaningless data panels. Icons, when essential, use a consistent restrained simple stroke system; otherwise rely on text and layout.
Create a new small, professional AIGuide brand mark consistent with this specific design direction. Do not approximate other companies' logos. No unexplained English in previews. No watermark. Do not put concept names or numeric variant labels inside the image.
