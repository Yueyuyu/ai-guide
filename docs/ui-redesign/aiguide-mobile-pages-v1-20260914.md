# AIGuide 手机端与关键状态 V1

日期：2026-09-14。阶段：静态设计，等待审阅。

## 本批覆盖

本批沿用已选首页、书页 Logo 和三色课程插图，使用内置 image_gen 生成。每张板包含三个独立手机画面，展示当前可见内容，不表示整篇长页的全部内容已经绘制。

| 方案板 | 三个画面 | 文件 |
| --- | --- | --- |
| 找到学习起点 | 首页、路线总览、路线详情 | [起点与路线](aiguide-mobile-start-v2.png) |
| 跟着教程学 | 教程正文、产品学习页、我的学习 | [阅读与学习](aiguide-mobile-learning-v1.png) |
| 查找工具与模型 | 工具目录、公司专题、模型排名 | [工具与模型](aiguide-mobile-discovery-v1.png) |
| 完成第一个成果 | 项目总览、项目任务进行中、项目完成后 | [实战流程](aiguide-mobile-practice-v1.png) |
| 遇到空白也能继续 | 搜索无结果、无学习记录、榜单更新失败且没有历史快照 | [空状态与异常](aiguide-mobile-states-v1.png) |

共 5 张方案板、15 个画面，涉及 11 种主页面的代表布局和 4 个附加状态。项目任务有两个状态；搜索只有无结果状态，不计为已完成正常搜索结果页。15 个画面不等于 15 种主页面都已完成手机适配。

## 布局决定

- 首页始终先给入门路线。三个基础课程纵向排列，保留人头与脑部、应用与模型层次、填充对话气泡三种图示。
- 路线详情将准备条件放在开始按钮之前。手机可以先读基础内容，电脑实操另作提示。
- 教程正文为单栏，收起桌面的旁栏目录。目录、收藏和图示放大入口可见；阅读顶部不出现已经完成课程的提示。
- 产品页先标明产品种类和使用入口，再列准备条件、操作教程与实战。豆包工作当前示意为 Windows 桌面版；不因为读者用手机浏览，就把入口改写成手机应用。
- 工具目录按公司分组，公司专题区分应用、编程工具与模型系列。应用和模型学习入口分开，图标保持各品牌原色。
- 榜单使用纵向条目，首要信息为用途、来源、模型版本、名次、分数、学习入口。无可核实数据时使用“—”，不把系列名当作完整参评版本。
- 我的学习突出当前一课，不增加时间统计、连续打卡和云同步。示例为入门路线已完成 1/6 课，进度与章节一致。
- 项目用阶段、成果和验收串联。阶段完成状态由用户明确标记，可以撤销；手机阅读任务不等于已经生成或保存了成果文件。

## 交互说明

以下是待实现约定，不代表图片已经包含可操作控件。

| 位置 | 用户操作 | 行为与反馈 |
| --- | --- | --- |
| 页头 Logo | 点击 | 返回首页 |
| 页头菜单 | 打开 | 显示学习路线、工具教程、模型指南，以及实战项目、我的学习等次级入口；主次分组保持清楚 |
| 页头搜索 | 点击 | 进入搜索；返回时恢复来源页的位置 |
| 继续学习 | 点击 | 有有效阅读记录时进入当前章节并保留路线来源；没有记录时进入学习起点 |
| 路线章节 | 点击 | 进入本路线下的文章；上一课、下一课按本路线计算，不能跳到另一条包含同课的路线 |
| 正文目录 | 展开、选择小节 | 显示可达的小节列表；选择后定位并折叠，标题不被页头遮挡 |
| 图示 | 点击放大 | 打开放大层，保留图示/截图性质说明；提供关闭入口，不裁掉重要标注 |
| 正文宽表 | 水平浏览 | 仅表格容器横向滚动，页面本身不溢出 |
| 下一节内容 | 点击 | 在本篇文章内前进，不能在未读完时自动标记整课完成 |
| 课末练习 | 选择、查看解析 | 未选择时给文字提示；解析解释原因，允许修改答案；不只用红绿表示对错 |
| 课程完成 | 用户点击完成 | 保存完成状态，显示明确文字反馈和撤销入口；下一课仍保留当前路线 |
| 收藏 | 切换 | 图标与“已收藏/收藏”文字同时变化；失败时恢复原状态并提示 |
| 复制示例 | 点击 | 仅在复制成功后显示“已复制”；失败给手动选择文本的入口 |
| 产品使用入口 | 切换 | 更新对应入口的准备条件和课程；没有教程时说明暂无，并推荐已有内容，不能复用另一端步骤充数 |
| 目录筛选 | 打开 | 在可关闭的底部面板中选择条件，含重置、应用按钮；应用后在结果上方显示条件与清除入口 |
| 搜索条件 | 清除 | “清除筛选”只移除筛选条件并保留查询词；搜索框清除按钮单独移除查询词 |
| 搜索返回 | 浏览器返回 | 恢复查询、条件与结果位置，避免回到初始空列表 |
| 榜单条目 | 展开 | 显示来源指标说明及软件/API 学习入口；模型系列信息与实际参评版本分开 |
| 榜单来源/用途 | 切换 | 对应状态明确；不同来源的名次与分数不拼接成自创综合榜 |
| 榜单重试 | 点击 | 请求期间按钮显示“正在获取”并阻止重复触发；成功后更换数据，失败后恢复重试入口 |
| 检查本阶段成果 | 点击 | 打开本阶段自查清单，逐项比对自己的成果；不伪装成系统已经自动验收 |
| 项目阶段验收 | 勾选、自查 | 复选框仅记录用户自查；未核对时不声称任务已通过系统实测 |
| 项目阶段完成 | 显式标记 | 更新阶段进度；撤销后恢复上一状态，保留其他阶段的记录 |
| 导出记录 | 点击 | 导出当前浏览器有效学习数据；无数据时说明无可导出的记录 |
| 导入记录 | 选择文件 | 先校验格式与版本，展示新增/合并/冲突摘要，再应用用户选择；异常文件不清空现有记录 |
| 本地存储失败 | 保存失败 | 明确提示本次记录没有保存，保留页面内状态，并给重试或导出入口 |

## 空状态与异常

已画出的三个恢复场景：

1. **无搜索结果**：显示查询词和已选条件，保留编辑查询、清除筛选、查看目录的去向；建议词不包装成真实热搜。
2. **无学习记录**：引导开始第一课，保留导入入口；不展示伪造进度和学习时间。
3. **榜单更新失败且没有历史快照**：显示来源和失败提示，可重试、查看来源、学习模型基础；不展示虚构版本、名次、分数或日期。

其他状态已有以下内容约定，但本批未画独立视觉稿：

| 状态 | 内容约定 |
| --- | --- |
| 榜单更新失败且有历史快照 | 继续显示上次成功快照及原始数据日期，独立标出更新失败；不得把重试时间写成源数据更新日期 |
| 榜单首次加载 | 保留用途和来源，让用户能辨认加载对象；骨架不带虚构名次与分数 |
| 正常查询但内容库暂无资料 | 说明暂无可用内容，保留来源与模型基础入口；与网络失败区分 |
| 当前平台没有教程 | 显示已选入口与确实存在的其他教程，空入口不做可点击假链接 |
| 找不到旧页面 | 保留相关目录和返回入口 |
| 记录损坏或导入失败 | 说明无法读取的原因，保留现有数据；不自动重置全部学习记录 |
| 教程资料暂缺 | 发布前补齐；正式页面不展示伪造产品截图 |
| 操作正在进行 | 仅锁定正在提交的操作，保留取消和离开页面的能力 |

## 不同屏幕与可访问性

这是后续实现的检查要求，尚未在浏览器验证：

- 320–767px 使用单栏。390px 为本批画面参考宽度，不以整体缩放代替更窄屏重排。
- 320px 下允许页头压缩间距，Logo、搜索、继续学习、菜单保持可用；必要时分行组织，不能挤出视口。
- 768–1023px 的平板布局需要另行检查；学习内容应优先保持可读行长，目录和侧栏不能挤压正文。
- 正文默认约 16px、行高约 1.7；补充说明避免过小，关键内容不能只藏在悬停提示里。
- 交互目标按至少 44px 设计；文字和背景、焦点环与底色在实现时进行对比度检查。
- 底部固定操作栏留出正文滚动空间及设备安全区，不遮挡最后一段内容。
- 菜单、筛选和放大层支持关闭按钮及 Escape。打开时移入焦点、限制弹层内焦点；关闭后返回触发控件并恢复页面滚动。
- 搜索结果数量、收藏反馈与复制反馈用可感知的状态提示；不把颜色作为唯一信息。
- 尊重减少动态效果设置；不依赖持续动画表达内容或迫使用户等待。

## 校对与材料限制

所有手机方案板都是 image_gen 生成的静态视觉参考，图标在最终实现时使用原始品牌资产。内容数字和操作文案以内容蓝图及本说明为准，生成图片中的扩写文案仍须逐项核对。豆包工作步骤和版本条件、外部入口与榜单数据均未由这次出图完成实测。

起点方案板 V1 在办公提效、AI 编程卡片上自行补出了未经核对的课数；V2 定向去除这两项数字，保留已拟定的入门 6 课。V1 仅存档，评审入口使用 V2。
