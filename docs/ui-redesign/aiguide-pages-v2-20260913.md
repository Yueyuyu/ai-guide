## 设计变化

- 保留左右两页，右页增加上扬的斜切轮廓，强化不对称的翻页感觉。
- 中间开口更加宽松、连贯，作为学习路径的视觉暗示。
- 字标与页头比例收紧，维持蓝白和深蓝文字的整体方向。
- 首页沿用已选的入门路线与三个预览；替换品牌标识，并统一课程图标和次级入口图标。

## 核对记录

已目视核对三张输出：书页与开口方向、品牌应用与独立标识的一致性、首页主要中文文案、软件/模型区分、三步结构和裁切情况。
品牌稿中的小尺寸示意用于视觉参考，不能视为浏览器真实16px渲染测试；最终落地时仍需以实际图标资源验证。
本轮为静态视觉精修，未修改网站代码，也未导出 SVG 或 ICO。独立 Logo 为白底 PNG。
提示词中的像素值是设计目标，生成图未保证逐项精确满足；实现时需要建立实际字号与间距规范。
