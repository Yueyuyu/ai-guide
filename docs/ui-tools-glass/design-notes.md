# 工具教程 · 公司玻璃卡片

日期：2026-09-15。范围：`#/tools` 和 `#/company/:id`。目标是让新手先找到公司，再按使用方式选择教程。

## 内容与交互

- 每家公司只展示实际有内容的网页版、桌面版、API、模型，不重复显示云端、桌面入口、终端等分类。
- 同一类中的产品显示短名称和原色图标。OpenAI 的 ChatGPT、Codex 分别保留学习入口，名称不表示它们必须各装一套软件。
- API 进入已有接入教程，例如 `#/learn/gpt-api-map`；模型进入 `#/model/gpt-models`。两者目的不同。
- 编辑器归入桌面版，链接仍携带真实 `platform=editor`。终端类在公司详情“进阶编程教程”中默认折叠；原教程 ID 和路径不变。
- 搜索以公司为整体，支持产品别名。分类一次只选一个，查询和分类写入 URL；空结果可同时清除关键词与分类。旧 `kind`、`platform` 链接兼容映射。
- 保留既有 12 家公司、31 个产品与模型。缺少对应内容时省略分类，不为卡片对齐而虚构入口。

## 视觉与实现

| 项目 | 当前实现 |
| --- | --- |
| 页面 | 白色既有导航，最大内容宽度 1280px，浅冷蓝背景 |
| 配色 | 背景 `#F1F5FF → #F8FBFF → #F0F5FF`，主操作沿用 `#2F63F3` |
| 卡片 | 透明白渐变、1px 白边、20px 圆角、16px 背景模糊；不支持模糊时回退实色 |
| 字体 | 系统中文无衬线；标题桌面 34px、手机 28px，公司名 20px，链接 13px／手机 12px |
| 图标 | 公司 56px／手机 48px，产品 21px；复用品牌原始资产，功能图标使用现有 Icon |
| 响应式 | 大于 1100px 三列，601–1100px 两列，600px 及以下单列；手机搜索与筛选分行 |
| 组件 | `ToolDirectory` 负责搜索分类；`CompanyLearningCard/Entries` 共享卡片与详情分区；`company-learning.js` 负责映射 |

## 概念稿与页面对照

设计源图：[桌面概念](concept-desktop.png)、[手机概念](concept-mobile.png)。最终页面：[桌面](desktop.png)、[平板](tablet.png)、[手机](mobile.png)、[公司详情手机](company-mobile.png)。

| 比较点 | 结果与有意调整 |
| --- | --- |
| 信息结构 | 保留公司头部、四类入口、底部全部教程；将旧的大产品行收成短链接 |
| 页头文案 | 主标题和描述按概念落地；搜索提示缩为“搜索公司或产品”，避免手机截断 |
| 网格与留白 | 桌面三列和手机单列与概念一致；卡片按实际内容决定高度，不用整体缩放 |
| 玻璃色彩 | 保留浅蓝背景、透明白卡片、细白边和轻阴影；降低背景装饰，保持文字可读 |
| 字体与字号 | 使用真实 HTML 和系统字体，按明确字号实现；生成图的字形不作为逐像素承诺 |
| 品牌图标 | 生成图对部分标识的重绘不准确；实现复用品牌原始文件和原色，包括阿里公司与 Qwen 产品的区别 |
| 手机导航 | 保留已有“继续学习”和菜单行为，不照搬概念中省略的导航项 |
| 公司数量 | 概念底部的额外模糊品牌不纳入数据；实现以现有 12 家公司为准 |

## 验证

31/31 Node 测试通过，Vite 7.3.6 生产构建通过（74 模块）。新增测试覆盖四类映射、API/模型不同目标、所有原产品可达、真实平台参数和旧分类链接。

Codex 内置浏览器完成桌面、平板、手机布局与主要跳转检查。最终测量含 1448×1086、768×1024、390×1100、320×900；本轮较早也检查 1366×768、1024×768。无整页横向溢出，图片加载后无破图。初次导航未完成图片加载的记录及后续复查一并保留，见 [浏览器记录](browser-checks.json)。

验证的交互包括桌面筛选、ChatGPT 桌面入口、API 正文和模型页、返回恢复分类、空搜索清除、Qwen Code 搜索与刷新、进阶折叠与原教程跳转、Cowork 两种使用端，以及无网页内容的公司详情引导。手机筛选与产品链接点击区至少 44px。未记录正常流程的控制台 error。

本轮没有修改教程正文或来源数据，没有重新核实第三方软件能力、账号实操与模型排名；没有公开部署。其他页面验证记录保留在项目根目录 `design-qa.md` 历史章节。
